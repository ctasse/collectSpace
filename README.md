# CollectSpace ✨

一个用于收藏和保存数据的应用。 📚

## 功能 🚀

*   **数据收藏**:  保存你喜欢的内容，例如文章、链接、图片等。 📝
*   **链接标题**:  自动获取链接的标题，方便管理。 🔗
*   **主题切换**:  支持多种主题，选择你喜欢的风格。 🎨
*   **分享**:  将你的收藏分享给朋友。 📢

## 下载安装方法
前往 ·release· 页面下载apk进行安装

## 构建方法 💡

1.  克隆本项目到本地。
2.  运行 `flutter pub get` 安装依赖。
3.  运行 `flutter run` 启动应用。
